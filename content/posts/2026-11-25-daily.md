### [Do inconsistent docs hurt AI coding agents?](https://devblogs.microsoft.com/blog/do-inconsistent-docs-hurt-ai-coding-agents/)
*Contradictory documentation can become an execution problem when coding agents turn guidance into changes.*

Microsoft’s account describes agents that notice disagreements between documentation pages yet still follow the wrong instructions, consuming extra tokens or producing a broken build. Detecting a contradiction and resolving it correctly are different tasks: an agent’s acknowledgment of ambiguity is not evidence that it has identified the authoritative source.

For engineering teams, this makes documentation consistency part of the development toolchain as well as a reader-experience concern. Clarifying which guidance supersedes older instructions is a practical response, although the supplied excerpt provides no experimental design or results quantifying the effect. It supports a concrete failure mode, not a universal estimate of how much contradictory documentation degrades agent performance.

### [AWS Lambda Doubles Its Timeout to 30 Minutes After Eight Years at 15](https://www.infoq.com/news/2026/11/aws-lambda-30-minute-timeout/?utm_campaign=infoq_content&utm_source=infoq&utm_medium=feed&utm_term=global)
*A longer execution ceiling expands workload options without removing concurrency and integration constraints.*

InfoQ reports that AWS has increased the maximum timeout for on-demand Lambda Event Functions from 15 to 30 minutes across commercial regions, without opt-in or new pricing. The previous ceiling had been in place since 2018. This is a higher maximum for the specified function category, not evidence that every function now runs longer or that all Lambda execution modes have changed.

Longer permitted execution also changes capacity planning when workloads actually use it. The report notes twice the concurrency at the same request rate, three-hour SQS visibility timeouts, and Kafka mappings that must be recreated. Teams must therefore assess both whether a job now fits and how longer-running invocations affect surrounding systems. Unchanged pricing should not be read as a promise of unchanged total spend.
