The Decode the Stack podcast is the audio companion to the daily written
briefing. It is a concise, synthesized English-language narration of selected
headlines, with each publisher named. It is a bulletin, not a round-table
conversation or an independently reported news show.

## Listen and subscribe

- **On this page:** The latest playable episode appears below when its MP3 has
  been generated and published.
- **Podcast RSS:** [Subscribe in a podcast app](/podcast/feed.xml). The feed
  includes an episode only when a non-empty MP3 is available.
- **Written show notes:** Each episode links to its matching
  [source-linked edition](/posts/2026-11-02-daily/), which contains the
  original publisher links and excerpts.
- **Site RSS:** [Subscribe to written editions](/index.xml).

## Format

| Detail | What to expect |
|---|---|
| Language | English |
| Voice | A single synthesized English voice |
| Stories | Up to eight headlines from the matching edition |
| Topics | Software engineering, cloud, DevOps, AI, and security |
| Schedule | The publishing workflow runs daily; audio is published only when synthesis succeeds |

The narration reads headlines and credits their publishers. It does not include
the full linked articles; use the show notes for context and follow the source
links for complete reporting.

The RSS feed includes the authorized owner metadata for directory setup. The
show has not yet been submitted to Spotify or any other directory; submission
and any platform review still need to be completed in the creator account.
